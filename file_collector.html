Welcome to File Collector

This application helps you collect and copy specific files to a destination directory. You can use various filters and options to customize your file collection process.


Features:

  • Multiple source directory support
  • File pattern matching with wildcards
  • Extension-based filtering
  • Size-based filtering
  • Exclude patterns support
  • Preserve directory structure option
  • Copy, move, or hardlink modes
  • Dry run preview functionality
  • Detailed reporting and logging
  • CLI command generation
